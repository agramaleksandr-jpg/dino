# Динозавры · Триас и юра

Детская игра про динозавров. Играть в браузере: https://agramaleksandr-jpg.github.io/dino/

Отсюда же приложение для Android берёт новые версии: при запуске сверяет `update.json` со своим и докачивает только
изменённые файлы. Файлы сюда выкладываются скриптом — руками ничего менять не нужно.
